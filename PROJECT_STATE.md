## Known limitations

- Production SigLIP2/CLIP embedding remains unavailable pending artifact, license,
  dependency and resource approval. GeoCLIP global predictions remain a separate
  model-only path and do not fabricate Phase 3 retrieval hits.
- The current exact FAISS/SQLite/local filesystem adapters are demo-scale. Clustering
  expects an upstream bounded Top-K set. Process-local cache/rate/circuit state and
  local transaction serialization are not distributed production coordination.
- The remote Overpass transport is not enabled by default; local PBF and object
  storage are interfaces only. Map absence is neutral because completeness varies.
- ORB/homography is a CPU baseline for planar/local visual consistency. It is not
  geographic proof and can be inconclusive for viewpoint, seasonal, low-texture or
  non-planar scenes.
- Model and Phase 4 scores are uncalibrated relative values, not probabilities. The
  reviewed six-image smoke slice is too small and too landmark-heavy for calibration;
  GeoNames labels were not installed, so country/region label metrics were excluded.
